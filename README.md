## Carnival Carnage

Carnival Carnage was a 10-week Unreal Engine group project at Howest DAE, built by 2 programmers, 3 artists, and 1 game designer. More about the project can be found on [my website](https://revekkaandronikidu.com/projects/carnivalcarnage).

**Programming**

- **Revekka Andronikidu:** everything in the subfolders of `Source/StarterProject/`, plus `Trail.h` / `Trail.cpp` and `TrailCollisionComponent.h` / `TrailCollisionComponent.cpp`
- **Yenzo Devos:** all other files directly in `Source/StarterProject/`

**Art:** Jan Neubauer, Jasper Rosseel, Hendrik Sapyn

**Game design:** Gilles de Waele

The project was made in Perforce and moved to GitHub afterwards, therefore the lack of commit history.
